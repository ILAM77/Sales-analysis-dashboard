Sales Analysis Dashboard

Interactive sales dashboard using Excel, Power Query and Power BI

Project Overview

Ce projet consiste à analyser des données de ventes afin d’identifier les tendances régionales, les produits les plus rentables et les performances commerciales.

Dataset Description

Dataset synthétique contenant des transactions de ventes multi-produits et multi-régions.

  • Product ID
  • Sale Date
  • Sales Representative
  • Region
  • Sales Amount
  • Quantity Sold
  • Customer Type
  • Sales Channel

Key Performance Indicators (KPIs)

  • Total Revenue
  • Total Profit
  • Profit Margin
  • Quantity Sold
  • Top-Selling Products
  • Best Performing Regions

Key Insights

  • The West region generated the highest revenue.
  • Online sales channels showed strong growth.
  • Electronics products contributed significantly to sales.
  • Returning customers generated higher average sales.
